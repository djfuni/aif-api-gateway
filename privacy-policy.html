🔒 隐私协议

最后更新日期：2026年5月7日

一、引言

我们非常重视您的隐私保护。本隐私协议旨在向您说明我们如何收集、使用、存储和保护您的个人信息。请您在使用本服务前仔细阅读本协议。

我们承诺严格遵守《中华人民共和国个人信息保护法》等相关法律法规，采取合理有效的安全措施保护您的个人信息。

二、我们收集的信息

为了向您提供服务，我们可能会收集以下类型的信息：

信息类型具体内容用途
账号信息用户名、邮箱、密码（加密存储）身份识别与登录验证
联系信息QQ号、邮箱地址客服沟通、重要通知
使用数据API 调用记录、Token 消耗量计费、用量统计、服务优化
设备信息IP 地址、浏览器类型、操作系统安全防护、反欺诈
支付信息订单记录、交易流水财务对账、售后服务
✅ 我们明确不收集的内容：
  • 您的 API 调用内容（Prompt 和 Response）不会被持久化存储
  • 我们不会记录您的聊天记录用于训练
  • 不会向第三方出售您的个人信息

三、信息使用方式

我们收集的信息仅用于以下目的：

  • 提供、维护和改进本服务
  • 处理您的订单和支付
  • 发送服务通知（如余额不足、套餐到期提醒）
  • 防止欺诈和滥用行为
  • 遵守法律法规要求
  • 进行匿名化的统计分析（不识别个人身份）

四、信息存储与安全

  • 您的密码采用 bcrypt/SHA256 等加密算法存储，即使数据库泄露也无法直接获取明文
  • API Key 采用哈希存储，泄露后无法逆向还原
  • 传输过程使用 HTTPS/TLS 加密
  • 服务器部署在安全的数据中心，定期备份
  • 仅授权人员可访问用户数据，且需通过多重身份验证

五、信息共享与披露

我们不会将您的个人信息出售给任何第三方。仅在以下情况下可能共享信息：

  • 法律要求：应司法机关、行政机关依法要求提供
  • 服务提供：向为我们提供支付、服务器托管等服务的第三方服务商（受保密协议约束）
  • 安全需要：为防止欺诈、网络攻击等安全事件
  • 合并收购：如发生业务合并、收购，信息将随业务转移（会提前通知）

六、Cookie 与本地存储

我们使用 Cookie 和浏览器本地存储技术来：

  • 保持您的登录状态
  • 记住您的偏好设置（如主题、语言）
  • 分析网站流量和使用情况

您可以在浏览器设置中禁用 Cookie，但可能影响部分功能正常使用。

七、您的权利

根据相关法律法规，您享有以下权利：

  • 知情权：了解我们如何处理您的个人信息
  • 访问权：查看我们持有的您的个人信息
  • 更正权：要求更正不准确的个人信息
  • 删除权：要求删除您的个人信息（法律法规保留期限除外）
  • 撤回同意：随时撤回对个人信息处理的同意
  • 注销账号：申请注销账号，我们将删除您的个人信息

八、未成年人保护

本服务不面向未满 18 周岁的未成年人。如果我们发现收集了未成年人的个人信息，将立即删除。

九、第三方链接

我们的网站可能包含指向第三方网站的链接。请注意，这些网站有自己的隐私政策，我们不对其内容和隐私保护措施负责。
