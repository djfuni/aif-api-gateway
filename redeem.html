使用说明3 步快速完成兑换
第 1 步：确认登录账号

兑换码会发放到当前登录的本站账号。建议先检查页面右上角账号状态，避免给错账号。

第 2 步：输入兑换码

支持直接粘贴兑换码。系统会自动按大写处理，输入后点击“兑换 Token”即可提交。

第 3 步：查看到账记录

兑换成功后，余额会即时刷新，下方“最近兑换记录”也会同步显示兑换时间和到账 Token。

兑换说明使用前建议阅读
  • 兑换码通常只能在有效期内使用，过期或被禁用后将无法兑换。
  • 如果兑换码限制每用户兑换次数，超过限制会收到明确提示。
  • 兑换成功后 Token 会直接进入你的站内钱包余额，可在令牌继续创建 API Key 并使用。
  • 如果输入兑换码后没有反应，当前页面已经修复为独立兑换流程；也可点击“刷新”重新同步状态。
